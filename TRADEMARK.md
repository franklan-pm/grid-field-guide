# Name and branding

The source code is open (MIT, see `LICENSE`). The identity of the project is not part of that grant.

The following are not licensed for reuse:

- The name "Grid Field Guide", and the domain franklan.net
- The drawing-sheet presentation: the title block, sheet index, line legend and "DRAWN BY" credit as used on this site
- The logo and brand mark

If you fork this project, please:

- choose a different name and domain
- replace the title block, credits and about text with your own
- do not present your version as the official Grid Field Guide, or imply that Frank Lan endorses it

Using the code is welcome. Using the name and the look to pass your copy off as the original is not.
