Chapter 7 · Part 1 of 3 · Power plants

Where will the new power come from?

Demand is growing, so the grid needs new power plants. Every one of them has to get in line first: before a plant can connect to the transmission grid, it files a request and waits while the grid operator studies it. Those lines, called interconnection queues, are public. Imagine you're buying power for a utility or a data center. The queue is your shopping list. Here's what's on it, and how much of it you can count on.

Why the headline and the charts differ
† Hybrid batteries: the project data leaves out about 197 GW of battery capacity nationwide, so charts understate storage.

Many grid operators list a solar-plus-battery plant as one request and don't give the battery's size: 1,389 of the 1,716 active solar + battery requests in the data file list no battery size. Berkeley Lab fills the gaps with an estimate, using the battery-to-solar ratio from hybrids that do list both (Queued Up 2026, slides 8, 16 and 30), and includes it in the report's headline totals. The published project data leaves those estimates out, so every chart built from it, including the rest of this page, understates storage and solar + storage. The report doesn't publish the ratios. The estimated part is about 197 GW of the 2,061 GW. CAISO lists almost every hybrid's battery, so it needs little estimating. For ERCOT the report's total (408 GW) equals the project rows, so no estimate was added there, and the data file lists no separate battery size for ERCOT's hybrids. ⚠ Whether those rows hold the solar size or the whole plant is not stated; to confirm with Berkeley Lab.
